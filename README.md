# Smart Door Lock with Fingerprint Authentication, GPS Tracking, and NB-IoT

This project was developed as a final-year thesis for the Electrical Engineering
Program.

The system is a smart door lock prototype that integrates fingerprint
authentication, GPS tracking, and NB-IoT communication using the SIM7000E module.

## 🔧 Technologies

### Hardware

- Arduino Mega 2560 Pro
- R503 Fingerprint Sensor
- SIM7000E NB-IoT Module
- GPS Module
- Magnetic Lock
- Solid State Relay
- RTC DS3231
- I2C LCD
- Buzzer
- Push Button

### Software

- Arduino IDE / C++
- Flutter / Dart
- PHP
- MySQL
- REST API
- NB-IoT

## ⚙️ Key Features

- 🔐 User authentication using fingerprint recognition
- 📍 GPS tracking of the Smart Door Lock device
- 📱 Fingerprint control through a Flutter mobile application
- 📡 Device communication using SIM7000E over NB-IoT
- 📊 Activity monitoring and logging
- 📏 Distance calculation using the Haversine method
- 📈 Quality of Service (QoS) testing
